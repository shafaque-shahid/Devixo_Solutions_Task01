# Task01

## Project Overview

This project analyzes Pakistan's largest e-commerce dataset using Python. It focuses on preparing the data, exploring transaction patterns, and presenting findings through visualizations.

## Dataset

**Dataset:** Pakistan's Largest E-Commerce Dataset  
**Source:** [Kaggle dataset](https://www.kaggle.com/datasets/zusmani/pakistans-largest-ecommerce-dataset)

The notebook uses the dataset provided by Kaggle. When running it in Google Colab, upload the dataset file when prompted.

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Project Workflow

1. Load and inspect the dataset.
2. Clean and preprocess the data.
3. Perform exploratory data analysis (EDA).
4. Create visualizations to examine transaction patterns.
5. Summarize key insights and findings.

## Key Findings

* **Most frequently recorded category:** Mobiles \& Tablets (115,710 records).
* **Most common payment method:** Cash on Delivery (COD), approximately 46.53% of records.
* **Average item price:** approximately 6,348.75; the median was 899.
* **Most frequently recorded status:** complete (233,685 records).
* **Peak month by number of records:** November 2017 (83,928 records).

These findings describe the records analyzed in the notebook; they should not automatically be interpreted as unique orders or completed sales.

4. Review the analysis outputs and charts.
